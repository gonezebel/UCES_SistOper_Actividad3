# Actividad 3 - Sistemas Operativos

Pagina web interactiva para presentar la Actividad Obligatoria Nro. 3 de Sistemas Operativos.

## Ejecutar localmente

```powershell
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Publicar gratis en Streamlit Community Cloud

1. Subir este repositorio a GitHub.
2. Entrar a https://share.streamlit.io/.
3. Crear una app nueva desde el repositorio.
4. Seleccionar `streamlit_app.py` como archivo principal.
5. Deploy.

La consigna y la bibliografia estan ignoradas por Git para no subir archivos pesados o material privado.
